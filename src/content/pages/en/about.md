I'm Seunghoon Jung, a software developer based in Seoul, Republic of Korea. I studied mathematics, and I build manufacturing digital twin tools and full-stack web applications — from PySide6/QML desktop apps with 3D visualization to web toolchains built with Next.js, NestJS and FastAPI.

## What I work on

**Codeflex Co., Ltd. — Software Developer** (Oct 2025 – Present)

Government-funded R&D on manufacturing digital twins and PLC–robot integration.

- A web toolchain that links factory PLC logic (IEC 61131-3) with URDF robot models: PLCopen XML conversion, PLC–joint mapping, AI-assisted simulation sequence generation, and PLC ST reverse generation for Siemens SCL and Mitsubishi ST.
- A PySide6/QML desktop app for configuring virtual workcells, with QtQuick3D URDF visualization, joint control and inverse kinematics.
- A workcell monitoring app that combines OPC UA, WebSocket and MySQL KPI dashboards (OEE, throughput) with a live 3D digital twin. I also supported its TKC GS (Good Software) certification.

**Herss Co., Ltd. — Software Developer** (Aug 2023 – Oct 2025)

Ministry of Environment R&D on CFD sensor placement optimization software.

- A desktop app built with PySide (Qt) and VTK, which I later led the migration of to the web: React + Vite, VTK.js 3D visualization, FastAPI, and GitLab CI/CD auto-deployment.
- Sensor optimization models with the Chama library, and a FORTRAN SLAB fluid dispersion model migrated to Python.

Before moving into software I worked in sales management at Evezary (2021 – 2022), where daily ERP use shaped how I think about user-centric design. Before that I served as a Marine Corps ROTC officer and platoon commander (2019 – 2021).

I studied mathematics at Yonsei University (Mirae Campus, B.S., 2019), then trained through a Java full-stack bootcamp at Hi-Media Academy and the Hanghae Plus Backend program (Cohort 9), which covered TDD, clean architecture, Redis and Kafka.
