서울에서 일하는 소프트웨어 개발자 정승훈입니다. 수학을 전공했고, 제조 디지털 트윈 도구와 풀스택 웹 애플리케이션을 만듭니다. PySide6/QML 기반 3D 시각화 데스크톱 앱부터 Next.js·NestJS·FastAPI로 만든 웹 툴체인까지 폭넓게 다룹니다.

## 하고 있는 일

**(주)코드플렉스 — 소프트웨어 개발자** (2025.10 – 현재)

제조 디지털 트윈과 PLC–로봇 통합을 다루는 정부 지원 R&D 과제입니다.

- 공장 PLC 로직(IEC 61131-3)과 URDF 로봇 모델을 연결하는 웹 툴체인: PLCopen XML 변환, PLC–관절 매핑, AI 기반 시뮬레이션 시퀀스 생성, Siemens SCL·Mitsubishi ST용 PLC ST 역생성
- 가상 워크셀을 구성하는 PySide6/QML 데스크톱 앱: QtQuick3D URDF 시각화, 관절 제어, 역기구학
- OPC UA·WebSocket·MySQL KPI 대시보드(OEE, 처리량)와 실시간 3D 디지털 트윈을 결합한 워크셀 모니터링 앱. TKC GS(Good Software) 인증 획득도 지원했습니다.

**(주)헤르스 — 소프트웨어 개발자** (2023.08 – 2025.10)

환경부 과제로, CFD 센서 배치 최적화 소프트웨어를 개발했습니다.

- PySide(Qt)와 VTK로 만든 데스크톱 앱을 웹으로 마이그레이션하는 작업을 주도했습니다: React + Vite, VTK.js 3D 시각화, FastAPI, GitLab CI/CD 자동 배포
- Chama 라이브러리 기반 센서 최적화 모델, FORTRAN SLAB 유체 확산 모델의 Python 마이그레이션

## 배경

소프트웨어 개발 전에는 (주)이브자리에서 영업관리를 했고(2021 – 2022), 매일 ERP를 쓰면서 사용자 중심 설계에 대한 관점을 갖게 됐습니다. 그 전에는 해병대 ROTC 장교(소대장)로 복무했습니다(2019 – 2021).

연세대학교 미래캠퍼스에서 수학을 전공했고(학사, 2019), 하이미디어 학원의 자바 웹 개발자 풀스택 과정과 항해 플러스 백엔드 9기(TDD, 클린 아키텍처, Redis, Kafka)를 수료했습니다.
